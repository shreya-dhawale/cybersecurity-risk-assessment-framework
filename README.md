\# Cybersecurity Risk Assessment Framework



\## About the Project



This project focuses on cybersecurity risk assessment for small and medium-sized businesses (SMEs).



The project identifies common cybersecurity risks, evaluates their likelihood and impact, recommends suitable controls, and assesses the remaining risk after mitigation.



The assessment is based on the NIST Cybersecurity Framework (CSF) 2.0.



\## Project Work



The project includes:



\- SME Risk Register

\- 5×5 Risk Matrix

\- Risk Mitigation

\- Residual Risk Assessment

\- NIST CSF Mapping

\- Retail/E-commerce Case Study

\- Professional Services Case Study

\- Project Report

\- Project Presentation

\- References and Screenshots



\## Risks Assessed



| Risk ID | Risk | Initial Level |

|---|---|---|

| R001 | Phishing | Critical |

| R002 | Ransomware | Critical |

| R003 | Insider Threat | High |

| R004 | Unauthorized Access | High |

| R005 | Data Breach | High |



\*\*Risk Score = Likelihood × Impact\*\*
